# ULTRON Security System

A modular, voice-enabled AI assistant starter project.

## Planned features
- AI chat interface
- Voice input and spoken responses
- Futuristic animated orb interface
- Responsive dashboard and settings
- Optional hand-gesture interaction
- Configurable AI provider integration

## Security
- Never commit API keys, passwords, access tokens, or private credentials.
- Store keys locally in environment variables.
- Use provider free tiers within their published limits.
